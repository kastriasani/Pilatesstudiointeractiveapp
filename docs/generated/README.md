# Generated Contract Artifacts

These files are generated by npm scripts and should not be hand-edited.

- `api-manifest.json`: Route manifest extracted from backend `index.ts`.
- `frontend-fetches.json`: Route references extracted from frontend `src/` fetch calls.
- `docs-endpoints.json`: Endpoint references extracted from markdown docs.
- `api-contract-report.md`: Non-blocking comparison report.
- `preflight-snapshot.md`: Safety baseline snapshot for this branch.

Commands:

```bash
npm run api:manifest
npm run api:fetches
npm run api:docs
npm run api:check
npm run api:check:strict
```
